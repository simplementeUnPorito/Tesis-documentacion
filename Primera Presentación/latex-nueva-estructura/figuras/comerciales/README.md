# Material visual comercial

Reserva visual descargada el 18 de agosto de 2026 desde documentación oficial de
los fabricantes. Las imágenes insertadas en `01_problema_modelado.tex` conservan
la atribución y la cita bibliográfica correspondiente.

- Geometrics GeodeFlex: cinco fotografías oficiales, incluida la WebApp en PC,
  tableta y teléfono.
- PASI GEA24: las doce páginas del folleto y nueve páginas seleccionadas del
  manual que muestran menús y funciones del software.
- DMT SUMMIT X One: las dos páginas de la ficha técnica oficial.
- Geometrics Atom-3C: tres fotografías y las dos páginas de su ficha técnica.

Los archivos `contact-*.png` son hojas de contacto usadas sólo para revisión
visual. Se conservaron porque facilitan seleccionar alternativas durante el
posterior recorte a quince páginas.
