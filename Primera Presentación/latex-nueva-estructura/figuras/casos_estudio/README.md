# Procedencia de las figuras de casos de estudio

Esta carpeta conserva los artículos fuente completos, las imágenes extraídas sin
reinterpretar sus datos y las copias con nombres semánticos usadas en la presentación.
Los textos de figura en LaTeX identifican al trabajo original; este inventario permite
volver desde cada PNG a la página exacta del PDF.

## Criterio de uso

- No se alteraron curvas, escalas ni valores; solamente se extrajeron las imágenes
  incorporadas en los PDF y se les asignaron nombres descriptivos.
- La presentación conserva la cita bibliográfica en cada pie de figura.
- Antes de publicar o distribuir la presentación fuera del ámbito académico debe
  revisarse la licencia aplicable a cada obra y la política de reproducción de la
  editorial correspondiente.
