El servidor de demostraci\'on emula WebSocket, estados, tres nodos, escaneo de
redes e ingesta local. Las formas de onda son \textbf{se\~nales sint\'eticas
utilizadas para activar y documentar la interfaz}; no se presentan como
mediciones de campo ni como validaci\'on del sistema. Cada figura muestra una
sola pantalla por hito, elegida para que la diferencia con el hito anterior sea
legible sin repetir pesta\~nas de esclavo, temas o vistas auxiliares.
