\section{Tabla maestra de decisiones}
\label{sec:descartes}

secci\'on m\'as \'util para recordar \emph{por qu\'e} el sistema es como es ---y para
no volver a probar algo que ya se descart\'o con raz\'on.

\subsection{Los principios que sobrevivieron a todo}

\seleccionado{Ocho decisiones nunca se revirtieron, y son las que en la
pr\'actica definen el sistema:
\begin{enumerate}[itemsep=0.15em,topsep=0.25em]
\item \textbf{Fase lineal siempre.} Todo el filtrado que toca la se\~nal
conserva la fase, porque el m\'etodo mide fase.
\item \textbf{El instante cero lo define un flanco f\'isico}, no un mensaje.
\item \textbf{Determinismo temporal por hardware}, no por software.
\item \textbf{El protocolo es independiente del medio.} SPI $\to$ UART $\to$
I\textsuperscript{2}C sin tocar los \emph{frames}.
\item \textbf{El dato crudo no se toca.} Toda correcci\'on discutible ---red
el\'ectrica, polaridad, \'enfasis--- vive en post-proceso y es reversible.
\item \textbf{Nada se borra: se cuarentena o se archiva con el motivo.}
\item \textbf{Validar antes de borrar.} Lo reemplazado queda como referencia
hasta que el reemplazo se prueba.
\item \textbf{Un solo firmware, un solo controlador, un solo protocolo.}
Cada bifurcaci\'on evitada es un modo de falla evitado.
\end{enumerate}}
