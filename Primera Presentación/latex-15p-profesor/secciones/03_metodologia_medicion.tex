\section{Análisis de ondas Rayleigh}
\label{sec:metodologia}

Una perturbación aplicada en la superficie genera diferentes tipos de ondas, entre ellas ondas de cuerpo y superficiales. Para analizar la propagación de las ondas Rayleigh se establece una geometría de medición en la que la dirección longitudinal une la fuente con los puntos de observación, la dirección vertical es normal a la superficie y la dirección transversal completa el sistema de coordenadas.

El análisis de la dispersión requiere conservar tanto la evolución temporal del movimiento como la posición correspondiente a cada traza. Si $x_m$ representa la posición longitudinal del receptor y $t_n$ el instante de muestreo, el registro de la componente vertical $u_z$ puede organizarse como
\begin{equation}
	U[m,n]=u_z(x_m,t_n).
	\label{eq:registro-xt}
\end{equation}

Cada fila de esta matriz corresponde a una traza temporal adquirida en una posición determinada, mientras que el conjunto constituye un registro espacio--tiempo. La propagación de una componente coherente se manifiesta como una variación sistemática de su posición temporal entre las distintas trazas. Para que esta información pueda interpretarse correctamente deben conservarse tanto la geometría de adquisición como una referencia temporal común.

Una de las técnicas desarrolladas para analizar la dispersión de ondas superficiales es el análisis espectral de ondas superficiales (SASW). Este método utiliza dos receptores y estima, para cada frecuencia, la diferencia de fase entre las señales registradas. Su configuración instrumental es relativamente simple, aunque la estimación de fase puede presentar ambigüedades asociadas con un número entero de ciclos y la limitada redundancia espacial dificulta la separación de contribuciones superpuestas. Por esta razón, el procedimiento suele repetirse utilizando diferentes separaciones entre receptores \citep{Foti2014}.

El análisis multicanal de ondas superficiales (MASW) extiende este principio mediante la observación del movimiento en múltiples posiciones. La información espacial adicional permite identificar con mayor claridad patrones de propagación coherentes y distinguir diferentes contribuciones presentes en el registro. MASW se utiliza para la caracterización somera del terreno mediante mediciones realizadas desde la superficie y permite obtener registros que posteriormente pueden procesarse para determinar las características dispersivas de las ondas Rayleigh \citep{Park1998,Park1999,Foti2018}.

En una configuración MASW convencional, las señales correspondientes a las diferentes posiciones se adquieren simultáneamente mediante un arreglo de receptores. Sin embargo, la implementación de un arreglo completo incrementa el costo instrumental, ya que cada posición requiere un transductor y su correspondiente canal de adquisición. Una alternativa consiste en sintetizar la dimensión espacial mediante mediciones sucesivas, desplazando uno de los receptores y repitiendo la excitación bajo condiciones controladas \citep{LinAshlock2016}.

La arquitectura desarrollada en este trabajo fue concebida como un sistema multicanal ampliable. Para su evaluación experimental se utilizaron dos canales operativos: un receptor permaneció en una posición fija como referencia, mientras que el segundo fue desplazado secuencialmente a lo largo de las posiciones de medición. Esta configuración permite construir el registro espacio--tiempo a partir de adquisiciones sucesivas, manteniendo una referencia común que permite verificar la coherencia temporal entre ellas.

La aplicación de MASW establece así los principales requerimientos de la adquisición: conservar la información temporal y espacial de las trazas, mantener una referencia temporal entre registros y preservar adecuadamente la amplitud y la fase de las componentes de interés.
